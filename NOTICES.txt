派生差异（为什么要有我们自己的一份）
------------------------------------
上游把「模型调用用的 sk- API key」直接当作 New API 用户级路由的 Authorization
凭据发送。我们内部署的 New API 在 /api/user/self、/api/data/self、
/api/log/self* 这些路由上要求的是「访问令牌」（个人设置里生成的 access token），
因此上游在我们的网关上必然返回 401 AUTH_UNAUTHORIZED。本 fork 引入独立的访问
令牌配置项、修正取数端点集合，并把展示币种按网关自身声明改为人民币。

我们不再跟随上游更新；后续维护由我们自己负责。

本 fork 的改动集中在：凭据来源（settings 命名空间 newapi-wallet）、端点集合、
金额换算与展示币种、内部标识与回环路由改名（loostone-newapi-wallet /
/api/newapi-wallet）。
